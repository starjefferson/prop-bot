1. OVERVIEW & BOT ARCHITECTURE
--------------------------------------------------------------------------------
This project is an autonomous Head & Shoulders (H&S) algorithmic trading bot 
designed to execute trades on MetaTrader 5 (MT5) via MetaApi's Cloud SDK 
(RPC/Streaming Connection).

Key Architectural Features:
- Direct Cloud Communication: Operates via MetaApi (`metaapi.cloud-sdk`), routing 
  orders and historical candle requests directly to MT5 cloud servers without 
  requiring local desktop MT5 terminals or custom EAs.
- Decoupled Prop Firm Layer: Strategy logic is completely decoupled from prop firm 
  compliance rules. Supports Atlas Funded (2-Step, 1-Step, and Instant Zero models), 
  Alpha Capital, FTMO, and The5ers via a single environment variable (`ACTIVE_PROP_FIRM`).
- Autonomous Lifecycle: Runs 24/7 as a standalone Node.js cloud worker managed by PM2 
  on a Linux VPS (e.g., Oracle Cloud Always Free VPS).

3. HOW THE BOT WORKS (CORE STRATEGY & LOGIC PIPELINE)
--------------------------------------------------------------------------------
The bot operates in an automated 9-step pipeline executed at the top of every hour 
(:00:05 UTC) across all 7 major FX pairs (EURUSD, GBPUSD, USDJPY, USDCHF, USDCAD, 
AUDUSD, NZDUSD):

1. Smart Hourly Polling: Calculates exact milliseconds until 5 seconds past 
   the top of the next hour (:00:05 UTC) and sleeps until then to evaluate freshly 
   closed H1 candles.
2. Candle Data Ingestion: Streams 200 bars across 1W, 1D, 4H, and 1H timeframes 
   directly via MetaApi cloud historical endpoints (`account.getHistoricalCandles`).
3. Top-Down Trend Bias (3/4 SMA Rule): Calculates a 20-period Simple Moving Average 
   (SMA 20) on 1W, 1D, 4H, and 1H charts. Requires at least 3 out of 4 timeframes 
   to agree on trend direction (Price > SMA = BUY, Price < SMA = SELL).
4. Structural Pattern Detection: Scans 200 H1 bars for 3 structural swing points 
   (Left Shoulder s1, Head, Right Shoulder s2) and dynamic Neckline Zone boundaries.
5. Stop Loss & Take Profit Math:
   - Stop Loss (SL): Placed at the Right Shoulder (s2) peak/valley + 5-pip buffer 
     (0.0005 standard majors / 0.05 JPY pairs).
   - Take Profit (TP): Derived from historical Support/Resistance zones, enforcing a 
     strict 2.5 to 3.0 Risk-to-Reward (RR) window.
6. Pattern Fingerprinting Guard: Generates a unique setup ID 
   (`${symbol}_${type}_${headTime}`) stored in `history.json` to prevent re-trading.
7. Distribution Guard: Rejects trades if price has already distributed past the 
   neckline zone (buffer: 0.0020 standard majors / 0.20 JPY), preventing chasing late moves.
8. Prop Firm Compliance Interceptor (`PropRiskEngine`):
   - Validates equity against Static Max Loss Floors or Trailing High-Water Mark Floors.
   - Validates equity against Balance-Based Daily Loss Limits (reset at 00:00 UTC).
   - Checks weekend holding restrictions per active profile.
   - Calculates dynamic lot sizing (0.01 lot increments) matching configured risk %.
9. Execution & Routing: Executes market orders directly on MT5 via MetaApi RPC 
   (`connection.createMarketBuyOrder` / `createMarketSellOrder`).


4. OBTAINING METAAPI CREDENTIALS
--------------------------------------------------------------------------------
To connect your bot to Atlas Funded (or any MT5 prop firm account):

Step 1: Create a MetaApi Account
- Sign up at https://metaapi.cloud/ and go to the API Access Tokens dashboard.
- Copy your `API Token`.

Step 2: Add Your MT5 Account to MetaApi
- Click "Add Account" in the MetaApi dashboard.
- Select platform: `MetaTrader 5`.
- Select account type: `Cloud`.
- Enter your Atlas Funded MT5 Server name, Login, and Password.
- Once deployed and connected, copy the `Account ID` string.


5. LOCAL SETUP & INSTALLATION
--------------------------------------------------------------------------------
Prerequisites: Node.js (v18 or higher) installed.

Step 1: Clone or Download the Repository
  git clone https://github.com/your-username/prop-bot.git
  cd prop-bot

Step 2: Install Node.js Dependencies
  npm install

Step 3: Configure `.env.local`
  Create `.env.local` in the project root:

  # MetaApi MT5 Credentials
  METAAPI_TOKEN=your_metaapi_token_here
  METAAPI_ACCOUNT_ID=your_metaapi_account_id_here

  # Active Prop Firm Profile Selection
  # Options: 'atlas_funded_2step', 'atlas_funded_1step', 'atlas_funded_instant', 
  #          'alpha_capital', 'the5ers_high_stakes', 'ftmo'
  ACTIVE_PROP_FIRM=atlas_funded_2step

  # Risk & Strategy Configuration
  RISK_PERCENT=1.0
  MIN_RR=2.5
  MAX_RR=3.0
  MAX_CONCURRENT_TRADES=2

Step 4: Run Bot Locally
  node index.js


6. SWITCHING PROP FIRMS
--------------------------------------------------------------------------------
To target different evaluation profiles, change `ACTIVE_PROP_FIRM` in `.env.local`:

- Atlas Funded 2-Step Standard: `ACTIVE_PROP_FIRM=atlas_funded_2step`
  (10% Static Drawdown, 5% Daily Loss, Weekend holding allowed, News trading allowed)

- Atlas Funded 1-Step Standard: `ACTIVE_PROP_FIRM=atlas_funded_1step`
  (7% Static Drawdown, 4% Daily Loss, Weekend holding allowed)

- Atlas Funded Instant: `ACTIVE_PROP_FIRM=atlas_funded_instant`
  (5% Trailing Drawdown following High-Water Mark, 3% Daily Loss)

- Alpha Capital Group: `ACTIVE_PROP_FIRM=alpha_capital`
  (10% Static Drawdown, 5% Daily Loss, 2-minute average hold rule enforced)

- FTMO Standard: `ACTIVE_PROP_FIRM=ftmo`
  (10% Static Drawdown, 5% Daily Loss, Weekend holding restricted)


7. 24/7 ORACLE CLOUD VPS DEPLOYMENT (PM2)
--------------------------------------------------------------------------------
Because MetaApi processes MT5 execution in the cloud, no desktop GUI or Windows VPS 
is required. The bot runs on any lightweight Linux cloud instance.

1. SSH into your Ubuntu VPS instance:
   ssh -i /path/to/key.key ubuntu@YOUR_VPS_IP

2. Install Node.js 20.x & PM2 globally:
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt install -y nodejs git build-essential
   sudo npm install -g pm2

3. Clone repository and install dependencies:
   git clone https://github.com/your-username/prop-bot.git
   cd prop-bot
   npm install

4. Create `.env.local` file with production MetaApi keys:
   nano .env.local

5. Start the process with PM2:
   pm2 start index.js --name "atlas-prop-bot"
   pm2 save
   pm2 startup

6. Useful PM2 Commands:
   - Check status: `pm2 list`
   - View live terminal logs: `pm2 logs atlas-prop-bot`
   - Monitor CPU/Memory: `pm2 monit`
   - Restart process: `pm2 restart atlas-prop-bot`


8. TROUBLESHOOTING & COMMON ISSUES
--------------------------------------------------------------------------------
- "Missing METAAPI_TOKEN or METAAPI_ACCOUNT_ID":
  Check that `.env.local` exists in the project root and variables are populated.
- "ACCOUNT_NOT_FOUND" / "TIMEOUT":
  Verify that your MT5 account status in the MetaApi cloud console shows "DEPLOYED" 
  and "CONNECTED".
- "DAILY_LOSS_BREACH_GUARD" / "MAX_DRAWDOWN_BREACH_GUARD":
  The risk interceptor blocked an order because current floating equity or position 
  risk breached the active prop firm limits.
- "Setup Expired: Price already distributed":
  Price broke past the neckline zone several candles ago and moved beyond the 
  distribution limit, so the bot avoided chasing the entry.
